# CST 335 Big Data

Jeffrey Yabandith

Coursework for CST 335. Each week has its own folder with its own README
explaining that week's assignment and how to run it.

- [week1](week1/) - Designing the equipment lending desk database. Schema,
  sample data, and five basic queries in SQLite.
- [week2](week2/) - Performance. Baseline queries, indexes, optimized
  queries, and a CSV vs Parquet comparison in DuckDB.
